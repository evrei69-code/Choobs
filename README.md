# Choobs

Lightweight VPN client focused on Windows 7.

## Stack

- Electron 22
- HTML / CSS / JavaScript
- Go
- sing-box

## Current version

0.1.0 — initial UI prototype.

The Connect button currently simulates a connection. No real VPN connection is active yet.
